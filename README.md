# 💄 Beauty Parlour Management App

## 📖 About The Project

Beauty Parlour Management App is a native Android application developed to streamline and digitize beauty parlour operations. The app enables customers and salon owners to efficiently manage appointments, services, and customer records through an intuitive mobile interface.

Built using **Java**, **XML**, and **Firebase**, the application provides a reliable and user-friendly solution for modern beauty parlours.

---

## 🎯 Problem Statement

Traditional beauty parlours often rely on manual appointment booking and record maintenance, which can lead to:

* Missed appointments
* Scheduling conflicts
* Inefficient customer management
* Difficulty tracking services
* Increased administrative workload

This application helps automate these processes and improve overall salon efficiency.

---

## ✨ Features

### 📅 Appointment Booking

* Book beauty services directly through the app

### 💇 Service Management

* Real-time data storage using Firebase

---

## ⚙️ How It Works

### 1️⃣ User Registration/Login

Users create an account or log in securely.

### 2️⃣ Browse Services

Customers can explore available beauty services.

### 3️⃣ Book Appointment

Users select a service and schedule an appointment.

### 4️⃣ Data Storage

Appointment and customer data are stored securely in Firebase.

### 5️⃣ Appointment Management

Salon staff can manage bookings and customer records efficiently.
